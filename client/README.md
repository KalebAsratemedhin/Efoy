# Efoy client

Frontend for **Efoy — Your Hospital Companion**.

See the [project README](../README.md) for product overview, setup, and architecture.

## Quick start

```bash
npm install
npm run dev
```

Runs at [http://localhost:3000](http://localhost:3000). Configure `VITE_BACKEND_URL` in `.env` to point at the API.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Development server (port 3000) |
| `npm run build` | Typecheck + production build |
| `npm run preview` | Preview the production build |
| `npm run lint` | ESLint |
